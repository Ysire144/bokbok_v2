# 새로 받아야 할 그림 목록 (v0.13 기준)

표정 그림은 나중에 한 번에 처리하기로 했으니, 여기에는 **화질 때문에 새로 받아야 하는 그림**만 적었어.
"나오는 횟수"는 312개 장면에서 화면에 나오는 횟수이고, "누적"은 아래 11명 전체 노출 중 몇 %가 해결되는지야.

## 4. 나중에 한 번에 처리하기로 한 것 (표정)

표정 그림이 생기면 그 캐릭터의 `imgs`에 표정 이름을 넣고 `base`를 기본 표정으로 되돌리면, 표정 표시 92개가 그대로 살아나.
기본 표정이 바뀌어 있는 캐릭터는 아래와 같아.

- 항상 **미소(노말)**: 벨, 아스트라, 빛나, 시드, 네코미야, 앨리스, 록시, 벨리나, 시시아, 남궁우, **자오**
- 항상 **무표정**: 다이아린, 루시아, 의현
- 항상 **얼굴붉힘**: 수나
- 제일 먼저 필요한 표정: **벨 진지**(171장면), **아스트라 진지**(24장면)
