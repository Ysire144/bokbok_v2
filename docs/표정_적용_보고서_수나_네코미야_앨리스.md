# 표정 그림 4장 적용 보고서 (수나 2장, 네코미야 1장, 앨리스 1장)

새로 받은 표정 그림을 게임에 넣고 어느 장면에서 쓰는지 정했어.

## 1. 새로 들어간 그림

| 파일 | 설명 | 크기 |
|---|---|---|
| `images/characters/수나_경멸.webp` | 눈을 가늘게 뜨고 입을 앙다문, 경멸하는 표정 | 1116×2000, 150KB |
| `images/characters/수나_침착.webp` | 얼굴이 붉지 않고 살짝 웃는 침착한 표정 | 1116×2000, 152KB |
| `images/characters/네코미야_당황.webp` | 입을 벌리고 당황한 표정 | 1116×2000, 152KB |
| `images/characters/앨리스_표독.webp` | 눈썹을 찌푸리고 노려보는 표정 | 1116×2000, 153KB |

- **시드 고민 그림은 넣지 않았어.** 같은 이름(`시드_고민.webp`)으로 다른 세션(`claude/game-story-system-analysis-4ol5r5`, `[표정 이미지] 이블린·루시아·레미엘·시드`)이 이미 추가하고 장면에도 배치해서, 겹치지 않게 뺐어. 내가 만든 시드 그림도 있으니 그쪽 그림보다 이쪽이 낫다고 판단되면 말해줘.
- 배경은 이전 그림들과 같은 방식(rembg `isnet-anime` + 가장자리 정리)으로 지웠어. 오른쪽 아래 ✦ 워터마크는 가장 큰 덩어리만 남기는 단계에서 같이 지워졌어. 어두운 배경 위에서 확대해 봤을 때 하얀 테두리는 없었어.
- 위치는 따로 맞출 필요가 없었어. 기존 기본 그림(수나_얼굴붉힘, 네코미야_노말, 앨리스_노말)을 같은 크기로 줄여 겹쳐 보니 하체와 몸통의 어긋남이 가로 0.67~0.84px, 세로 0.33px 이내(1116px 기준, 폰 화면에서 0.3px 정도)였고 크기도 같아서, `adj` 없이 그대로 썼어.
- 이 작업 과정은 `tools/expr_cutout.py` 한 줄로 되풀이할 수 있게 도구로 묶어 뒀어 (`tools/README.md` 참고). 이 도구로 같은 그림을 다시 만들어 보면 지금 넣은 파일과 한 픽셀도 다르지 않아.

## 2. 코드에서 바꾼 것 (세 줄)

`bokbok27_3.twee`와 `index.html`의 `CHAR` 표:

```
'수나':     { imgs: ['침착', '경멸', '얼굴붉힘'], base: '침착', ... }   // 전: imgs ['얼굴붉힘'], base '얼굴붉힘'
'네코미야': { imgs: ['노말', '당황'], base: '노말', ... }
'앨리스':   { imgs: ['노말', '표독'], base: '노말', ... }
```

- **수나의 기본 표정이 `얼굴붉힘`에서 `침착`으로 바뀌었어.** 화질 정리 때 얼굴붉힘 한 장만 남아서 모든 장면에서 얼굴이 빨갰는데, 이제 표시가 없는 장면은 침착한 표정이야. 얼굴이 붉은 장면(당황하는 장면)에는 `수나:얼굴붉힘` 표시를 따로 넣었어.
- 미리 받기 목록은 `CHAR`의 `imgs`를 읽어서 만들어지니까 새 그림은 자동으로 들어가. 미리 받기 코드는 안 건드렸어.

## 3. 장면 배치 (표시 25곳)

장면 글 맨 위 표시 줄들 끝에 `<span data-bx="수나:경멸"></span>` 같은 줄을 넣었어(대사 글은 안 고침). 번호는 `제목 없는 구절 N`의 N이야. 어떤 인물이 무대에 서 있는 장면인지는 17개 엔딩 경로를 실제로 플레이하면서 장면마다 무대 상태를 기록해서 찾았어.

| 인물 | 표정 | 장면 | 고른 기준 |
|---|---|---|---|
| 수나 | 얼굴붉힘 | 89 (+ 이미 표시가 있던 시작7, 구절, 86, 87) | 말을 더듬으며 당황하는 장면 |
| 수나 | 침착 | 90, 91 (표시 없이 기본 표정) | 아리아가 "조용히 하세요"라고 하고, 수나가 "네...?" 하고 되묻는 순진한 순간. 바로 다음에 경멸로 바뀌는 대비 |
| 수나 | 경멸 | 92, 93, 94, 96, 97, 99 | "수나의 분위기가 급변했다" 부터 권총을 꺼내고 "너도 죽어" 까지 |
| 네코미야 | 당황 | 114, 155, 156, 231, 294, 295 | "반려묘는 되냥...?", "살려달라냥... 배가 터질 것 같다냥", 레시피 폭로에 놀람, 십만 데니가 되어 "네...?", "곤경에 빠진 고양이 귀 소녀" |
| 앨리스 | 표독 | 187, 188, 189, 190, 191, 192, 193, 194, 196, 197, 198, 202 | "표독스러운 표정으로 노려보았다"부터 "집중!!!" 연발, 놀래키지 말라고 화내는 장면까지 |

- 114번은 원래 `네코미야:노말` 표시가 있어서 줄을 새로 넣지 않고 표정만 `당황`으로 바꿨어.
- 앨리스는 이 장면들 사이에도 기본 표정이 나오는 곳이 있어. 186번(질문하기 전), 195번과 200~201번(앨리스가 무대에 없음), 203번("기절 좀 하고..." 힘 빠진 말투)이야.
- 네코미야 150번("와아!! 저요 저요!")과 321번("야옹~")은 들뜬 장면이라 기본 표정으로 뒀어.
- 앨리스 197번은 선택지 장면이라 앞 장면의 표정을 이어받지만, 뒤로 돌아갔을 때도 같게 나오도록 표시를 따로 넣었어.
- 다른 세션과 겹치지 않게 확인했어: `compassionate-mendel`(아리아·아스트라·시시아·야나기), `game-story-system-analysis`(이블린·루시아·레미엘·시드), `tender-pascal`이 바꾼 패시지 중에 내가 고친 패시지는 하나도 없어. (수나 87, 90, 91번은 아리아 쪽이 고치지만, 나는 90, 91번을 기본 표정에 맡기고 안 건드렸어.)

## 4. 확인한 방법

- **구조**: `tools/check_sync.py` (스크립트, 스타일시트, 패시지 369개가 `twee`와 `index.html`에서 같음, 문법 OK).
- **엔딩 17개 플레이**: 정해진 선택지대로 실제로 플레이해서 17개 모두 맞는 엔딩 글에 도달 (불일치 0, 그림 없음 상자 0, 콘솔 에러 0, 실패한 요청 0).
- **표정이 실제로 나오는지**: 수나 89(얼굴붉힘), 91(침착), 92, 94(경멸), 네코미야 114, 155, 295(당황), 앨리스 115(기본), 188, 190(표독)을 폰 크기(390×844)로 찍어서 눈으로 확인했어. 표정이 바뀌어도 얼굴 위치는 그대로야.

## 5. 남은 것
- 이 그림들로 `docs/새_그림_요청_목록.md`(다른 세션이 쓴 파일이라 안 고침)의 "수나 기본 표정이 항상 얼굴붉힘" 항목은 풀렸어.
- 어색한 장면이 있으면 알려줘. 해당 장면 번호의 표시 한 줄만 바꾸면 돼.
