# 시시아 표정 순서 + 레미엘 스킵 버튼 보고서

## 1. 시시아: 꾸중을 듣기 전에는 기본 표정, 듣고 난 뒤에는 울상

시시아가 나오는 장면은 3, 4, 5, 8번 네 곳뿐이야.

| 장면 | 상황 | 시시아 표정 |
|---|---|---|
| 3 | 늦게 도착해서 귤복복을 치고 지나감 | 노말(기본) |
| 4 | 11호가 "30분 일찍 도착하는 게 예의입니다" 하고 꾸중 | 노말(기본) |
| 5 | "아아아... 제... 제성합니다아..." | **울상** |
| 8 | 빛나와 같이 나오는 장면 | **울상** |

- 지금까지는 기본 표정이 `울상`이라 3번부터 계속 울상이었어. `CHAR`의 `'시시아'`를 `imgs: ['노말', '울상'], base: '노말'`로 바꿔서 기본을 노말로 되돌렸어.
- 5번과 8번 맨 위에 `<span data-bx="시시아:울상"></span>` 한 줄씩 넣었어. 꾸중을 듣고 난 뒤(5번)부터 쭉 울상이야.
- 두 그림은 서로 0.8px(1116px 기준) 차이로 같은 자리라서, 4번에서 5번으로 넘어갈 때 시시아가 튀지 않아.

## 2. 레미엘 심문 루트의 스킵 버튼

레미엘 엔딩을 이미 본 사람이 다른 엔딩을 보려고 다시 올 때, 레미엘 심문 장면을 계속 눌러야 했던 걸 줄였어.

### 어떻게 보이고 동작하는지

- 모양: 오른쪽 위, 홈 버튼 바로 왼쪽에 같은 높이로 붙은 작은 버튼. **오른쪽 화살표 두 개(≫) + "스킵"**. 홈 버튼과 같은 주황색 스타일이고, 폭은 홈 버튼의 두 배(폰 화면에서 78×39px).
- 보이는 때: **레미엘 엔딩(1번이나 2번)을 하나라도 본 사람**이 레미엘 심문 장면(제목 없는 구절 19, 22~33번 13곳)에 있을 때. 엔딩을 안 봤거나 레미엘과 상관없는 엔딩만 봤다면 안 보여.
- 누르면: 양자택일 선택지가 나오는 **34번**(벨: "그렇구나... 혼자서 케이크를 만들고 있었다라..." + `범인으로 몬다 / 추궁한다`)으로 바로 이동. 34번에서는 버튼이 사라져.
- 이동한 뒤 모습은 33번에서 이어진 것과 같아(벨 고뇌 + 아리아 미소, 벨은 왼쪽 / 아리아는 오른쪽).
- 이전 대사 버튼은 그대로 써: 34번에서 누르면 스킵을 누른 장면으로 돌아오고, 거기서 스킵 버튼이 다시 보여.

### 만든 방식 (다른 루트에도 쓸 수 있게 범용으로)

- 장면 글 맨 위에 `<span data-skip="도착할 패시지 이름" data-skip-ending="1,2"></span>` 를 넣으면 그 장면에 스킵 버튼이 생겨. `data-skip-ending`은 "이 엔딩 번호 중 하나라도 봤을 때만"이고, 안 쓰면 항상 보여.
- 이동은 헤더 패시지 `홈 버튼 링크`에 숨겨 둔 `|skip>[ [[제목 없는 구절 34]] ]` 링크를 눌러서 해(홈 버튼이 쓰는 방식과 같아). 새 도착지를 쓰려면 이 줄에 `[[패시지 이름]]`을 하나 더 적으면 돼.
- 본 엔딩은 기존 기록(`BB.load()`)을 읽어서 판단해.

### 바꾼 곳

- 새 JS 블록(`skipSync` 등) 하나와 `onPassage`에 한 줄 호출, 스타일시트에 `.hm-skip` 규칙 몇 줄.
- 헤더 패시지 `홈 버튼 링크`에 숨은 링크 한 줄.
- 패시지 19, 22~33 맨 위에 `data-skip` 표시 한 줄씩.
- 패시지 34 맨 위에 `data-stage="벨,아리아"`와 `data-bx="아리아:미소"` 두 줄. 건너뛰어 와도 33번에서 이어진 모습이 되게 하려는 거야. 원래 순서로 와도 모습은 같아.

### 덤으로 고친 것

- 34번에는 `벨:고뇌` 표시만 있어서 **아리아의 미소가 풀려 기본 표정으로 돌아가고 있었어**(표시가 하나라도 있으면 앞 장면의 표정을 안 이어가는 규칙 때문). 위의 `아리아:미소` 한 줄로 31~33번의 미소가 34번에서도 이어져.

## 3. 알아둘 것

- 스킵 버튼이 건너뛰는 장면은 22~33번(레미엘의 문답 시작과 아리아의 복숭아 케이크 이야기)이야. 레미엘 엔딩을 이미 본 사람에게만 보이는 버튼이라, 건너뛰는 내용은 한 번 본 장면이야.
- 버튼 위치는 홈 버튼 왼쪽이야. 이전 대사 버튼은 왼쪽 위라 안 겹쳐.
- 테스트 메뉴로 "모든 엔딩 열기"를 하면 엔딩 1, 2도 본 것으로 취급되니까, 테스트할 때 버튼이 보여.

## 4. 확인한 방법

- **구조 검사**: 패시지 369개가 `twee`와 `html`에서 글자 단위로 같고, 깨진 링크 0, 엔딩 17개 (오류 0).
- **312개 장면 전수**: 실제 엔진으로 모든 장면을 열어 나오는 인물과 표정을 확인 (불일치 0, 에러 0, 404 0).
- **시시아**: 3, 4, 5, 8번을 폰 크기로 찍어서 확인 (3, 4번 노말 → 5, 8번 울상).
- **스킵 버튼**(390×844 폰 크기와 1280×720 데스크톱 둘 다):
  - 엔딩 2를 본 상태로 19번에서 시작해 33번까지 눌러 가며, 13개 장면 모두에서 버튼이 보이는지 확인
  - 중간(26번)에서 누르면 34번으로 이동하고, 벨 고뇌 + 아리아 미소, 선택지 2개, 버튼 사라짐 확인
  - `추궁한다`를 누르면 36번으로 이어지고, 이전 대사 버튼으로 34번 → 스킵을 누른 장면으로 돌아오며 버튼이 다시 보이는 것까지 확인
  - 엔딩 기록이 없거나 빈 기록이거나 레미엘과 상관없는 엔딩(5, 6번)만 본 상태에서는 버튼이 안 보임, 엔딩 1번만 본 상태에서는 보임
  - 다른 심문 루트(100번)와 용의자 선택 화면(15번)에서는 버튼이 안 보임
  - 버튼이 홈 버튼 왼쪽에 같은 높이로 붙고 화면 안에 들어오는지, 이전 대사 버튼과 안 겹치는지 위치도 숫자로 확인
- **무작위 플레이 20판**(390×844 12판, 360×640 8판): 처음부터 선택지를 무작위로 골라 엔딩까지 가고, 에러와 멈춤 0.
- **그 밖의 회귀 검사**: 엔딩 17개(이상 0), 선택지 클릭 48곳(이상 0), 대사창만 눌러야 넘어가는 동작, 시시아가 귤복복을 치는 연출, 타이틀 화면 모두 정상. (타이틀 검사 스크립트가 없앤 버전 표시를 찾다 멈춰서 그 항목만 빼고 돌림. 게임 문제는 아님.)
- 구조 검사의 경고 1건(`아스트라_당황.webp`가 안 쓰임)은 다른 Claude가 `main`에 넣은 그림이라 이번 작업과 무관해.
