# 링크 미리보기(공유 정보)와 파비콘 보고서

링크를 카톡, X(트위터), 디스코드 등에 붙였을 때 뜨는 **미리보기 카드**와, 브라우저 탭의 **작은 아이콘**을 넣었어.

## 1. 뭐가 바뀌었나

| 항목 | 내용 |
|---|---|
| 설명 문구 | `젠레스 존 제로의 무료 팬게임, 바로 즐겨보세요` (사용자가 정함) |
| 미리보기 그림 | `images/share-card.jpg` (1200×630, 177KB). 해변 배경 위에 제목 로고(타이틀 그림과 같은 분홍 글씨에 흰 테두리, 노란 `Zzz fangame`)와 귤복복, 벨, 레미엘 |
| 파비콘 | `favicon.ico`(16, 32, 48px, 저장소 맨 위), `images/favicon.png`(64px), `images/apple-touch-icon.png`(180px, 아이폰 홈 화면용). 귤복복 얼굴에 게임의 청록색 배경 |
| 그 밖에 | `<html lang="ko">`(스크립트로 설정), 브라우저 주소창 색(`theme-color`, 게임의 짙은 남색) |

기존 그림은 하나도 덮어쓰지 않았어(전부 새 파일).

## 2. 어디에 들어갔나

- `head.html`과 `index.html`의 `<head>`, 첫 화면 스타일(`<style id="bb-splash">`) 바로 앞에 같은 줄 (`description`, `og:*`, `twitter:*`, `theme-color`, 아이콘 `<link>`, `lang` 스크립트).
- 이전과 똑같이 `index.html`은 `head.html`을 Tweego로 합친 모양이라서 두 파일을 같게 맞췄어. 스토리, 엔진, CSS는 안 건드렸어.

## 3. 주소 (확인 필요)

`og:image`, `og:url`, `twitter:image`는 **절대 주소**여야 해서 아래 주소로 적었어.

```
https://ysire144.github.io/bokbok_v2/
```

- 저장소에 GitHub Pages가 켜져 있고(`has_pages: true`) 사용자 정의 도메인(CNAME) 흔적이 없어서, GitHub Pages 기본 주소로 추정한 거야. **이 환경에서는 github.io에 접속이 막혀 있어서 실제로 열리는지는 못 봤어.**
- 실제 주소가 다르면 `head.html`과 `index.html`에서 위 주소가 들어간 3줄(`og:url`, `og:image`, `twitter:image`)만 고치면 돼.

## 4. 확인한 방법

- 로컬 서버에서 HTML만 읽어서 `description`, `og:*`, `twitter:*`, 아이콘 링크가 모두 제대로 읽히는지 확인.
- 실제 브라우저(Chromium, 폰 크기)로 열기: `lang=ko`, 제목 정상, 타이틀 화면 정상, 첫 화면(스플래시)이 사라지는 것, 4xx 응답 0, 페이지 에러 0. 전에 접속할 때마다 찍히던 파비콘 404 한 줄이 사라졌어.
- 전 경로 18개를 엔딩까지 자동 플레이: 전부 도달, 에러 0.
- `tools/check_sync.py` 통과.
- 공유 그림과 아이콘은 만든 뒤 눈으로 확인했어(글자 안 잘림, 파비콘 16~180px에서 얼굴이 알아볼 만함).

## 5. 알아둘 것

- **한 번 공유한 링크는 앱이 미리보기를 기억해서 늦게 바뀔 수 있어.** 카톡은 새로 올려도 이전 미리보기(제목만 나오던 것)가 한동안 남을 수 있고, 새 미리보기를 보려면 주소 뒤에 `?v=2`처럼 아무 글자를 붙여서 공유해 보면 돼. X는 카드 검사 도구에서 다시 읽게 할 수 있어.
- 이 미리보기 그림은 로고 글씨체가 실제 타이틀 그림의 글씨체와 같지는 않아(비슷한 둥근 굵은 글씨로 맞춤). 타이틀 그림 원본(399×713)이 너무 작아서 직접 쓰지 못했어. 더 큰 로고 원본이 생기면 바꿀 수 있어.
- 파비콘은 브라우저가 오래 기억해서, 이미 접속해 본 사람은 새 아이콘이 늦게 보일 수 있어.
