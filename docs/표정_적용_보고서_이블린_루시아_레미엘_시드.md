# 표정 그림 5장 적용 보고서 (이블린, 루시아, 레미엘, 시드, 아스트라)

새로 받은 표정 그림 5장 중 4장(이블린, 루시아, 레미엘, 시드)을 게임에 넣고 장면에 배치했어. 아스트라 1장은 그림 파일만 넣고 연결은 보류했어(아래 5번).

## 1. 새 그림

| 파일 | 표정 | 크기 |
|---|---|---|
| `images/characters/이블린_씨익.webp` | 흑심을 품고 씨익 웃는 얼굴 | 1116×2000, 118KB |
| `images/characters/루시아_미소.webp` | 방긋 웃는 얼굴 | 1116×2000, 192KB |
| `images/characters/레미엘_시무룩.webp` | 입꼬리가 살짝 내려간 얼굴 | 1116×2000, 452KB |
| `images/characters/시드_고민.webp` | 턱에 손을 대고 살짝 고민하는 얼굴 | 1116×2000, 137KB |
| `images/characters/아스트라_당황.webp` | 엄청 당황한 얼굴 (아직 `CHAR`에 연결 안 함) | 1116×2000, 211KB |

기존 그림은 하나도 덮어쓰지 않았어. 전부 새 파일 이름이야.

## 2. 어떻게 처리했나

- 원본은 모두 1116×2000에 배경이 불투명이었어(흰 배경 4장, 레미엘만 검은 배경). 이전 그림들과 같은 방식(rembg `isnet-anime`)으로 배경을 지우고, 오른쪽 아래 ✦ 워터마크도 같이 지웠어. webp 품질 84.
- `isnet-anime`만 쓰니까 얇은 고리(루시아 지팡이)나 CD(아스트라 마이크), 소매와 몸 사이에 뚫린 틈(이블린)이 반투명하게 번지거나 틈이 막혔어. 그래서 **기존 그림과 구도가 같은 곳은 기존 그림의 깨끗한 윤곽을 쓰고, 표정이나 손이 달라진 곳만 새로 지운 윤곽을 쓰도록** 섞었어. 색은 항상 새 그림 픽셀 그대로야(표정이 기존 그림 색으로 덮이지 않아).
- 구도 정합: 새 그림과 기존 그림을 겹쳐서 크기와 위치 차이를 쟀어.
  - 루시아, 시드, 아스트라: 기존 그림(1340×2400)과 완전히 같은 구도(차이 0.1px 이하)라서 보정 없음.
  - 이블린, 레미엘: 새 그림이 기존보다 1.2% 크고 왼쪽으로 5.5px 치우쳐 있어서 `adj`로 맞춤(이블린 `[0.9881, 0.0029, 0.0001]`, 레미엘 `[0.9881, 0.0028, 0]`).
- 완성한 5장은 투명한 덩어리가 본체 하나(시드만 치마 옆면 조각 3개가 따로 떨어져 보이는데 진짜 치마 부품이야)이고, 워터마크 자리에 남은 점은 0개야.

## 3. 코드에서 바꾼 것 (`bokbok27_3.twee`와 `index.html` 양쪽, `CHAR` 네 줄)

```
'레미엘': imgs ['진지']   -> ['진지', '시무룩']  + adj: { '시무룩': [0.9881, 0.0028, 0] }
'이블린': imgs ['진지']   -> ['진지', '씨익']    + adj: { '씨익': [0.9881, 0.0029, 0.0001] }
'루시아': imgs ['무표정'] -> ['무표정', '미소']
'시드':   imgs ['노말']   -> ['노말', '고민']
```

- `base`(표정을 안 정한 장면에서 나오는 그림)는 그대로야. 이블린, 레미엘은 `진지`, 루시아는 `무표정`, 시드는 `노말`.
- 미리 받기 목록은 `CHAR`의 `imgs`를 읽어서 만들어지니까 새 그림은 자동으로 들어가. 미리 받기 코드와 `sw.js`는 안 건드렸어.

## 4. 장면 배치 (표시 16곳)

장면 글 맨 위의 표시 줄에 `<span data-bx="이름:표정"></span>`을 넣었어(이미 있는 표시 줄이 있으면 그 아래에 넣고, 같은 인물 줄은 그 줄만 바꿈). 대사 글은 안 고쳤어.

| 표정 | 곳수 | 장면 (`제목 없는 구절 N`) | 고른 기준 |
|---|---|---|---|
| 이블린 씨익 | 4 | 75, 76, 79, 80 | 이블린이 아스트라를 범인으로 몰아가며 "스위스에서 단둘이..."를 말하는 장면(엔딩 3 루트). 76, 80은 아스트라가 당황해서 외치는 동안 이블린은 말없이 웃고 있어 |
| 루시아 미소 | 3 | 107, 317, `트리거 추가5` | "포포랑 놀면서 간식 주고 있었어", "예삐 왔어? 오로로로로", "예삐 왔어? 야옹~ 에옹~" |
| 레미엘 시무룩 | 5 | 41, 246, 271, 274, 276 | 낙인 효과 항의("너무해요"), "그만... 내가 전부 설명할게", "차라리 날 죽여!", "할...", "100살 이상이면 할머니네요" 억울함 |
| 시드 고민 | 4 | 130, 273, 277, `시드 추가5` | 트롤리 딜레마를 받고 "으음... 어려운 질문이네", "동기가 없는 거야?", "확실히 그건 너무할지도..." (추가5는 벨이 질문하는 동안 시드 표정) |

- 273, 시드 추가5는 원래 `시드:노말` 표시가 있어서 그 줄만 `시드:고민`으로 바꿨어.
- 274, 275, 276은 원래 `시드:노말` 표시가 있어서 그대로 웃는 표정이야(레미엘이 말을 못 잇는 동안 시드는 웃고, 277에서 다시 고민).
- 표시한 16곳은 모두 그 인물이 화면에 서 있는 장면이야(말하는 사람이거나 옆에 서 있는 사람).

## 5. 아스트라 당황 (연결 보류)

`[표정 이미지 2]`(`claude/compassionate-mendel-99mj8t`)가 `CHAR`의 `'아스트라'` 줄과 아스트라 장면을 맡고 있어서, 겹치지 않게 **그림 파일만 넣었어.** 그쪽이 머지된 뒤에 `imgs`에 `'당황'`을 더하고 장면에 표시를 넣으면 돼. 보정(`adj`)은 필요 없어(기존 그림과 구도 완전히 같음).

쓸 만한 후보(아스트라가 당황하는 대사): 66, 72, 74, 76, 80, 243. 지금은 연결 안 했어.

## 6. 확인한 방법

- `tools/check_sync.py`: 스크립트, 스타일시트, 패시지 369개가 `twee`와 `html`에서 같고 문법 정상.
- 실제 엔진(Chromium, 390×844)에서 **전 경로 18개**(선택지를 전부 돌고 진엔딩까지)를 자동으로 끝까지 플레이: 전부 엔딩 도달, 이미지 404 0개, "이미지를 못 찾았어" 자리표시 0개, 게임 에러 0개. 콘솔에는 파비콘 404 한 줄만 있었어(이전부터 있던 것, 이번 작업과 무관).
- 표시한 16곳이 모두 의도한 표정으로 나오는지 장면별로 확인(정상, 못 찾은 장면 0).
- **표정이 바뀌어도 위치가 안 튀는지**: 같은 자리에 선 직전 장면과 겹쳐서 어긋남을 쟀어. 이블린 0.25px, 레미엘 0.32px, 루시아 0.23px, 시드 0.17px (폰 화면 기준).
- 눈으로 확인: 폰 크기로 8장면(이블린 75, 79 / 루시아 107, 317 / 레미엘 41, 271 / 시드 130, 277)을 찍어서 표정과 가장자리를 봤어.
