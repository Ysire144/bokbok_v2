# 표정 그림 5장 적용 보고서

새로 받은 표정 그림 5장(벨 4장, 니콜 1장)을 게임에 넣고, 어느 장면에서 쓰는지 정했어.

## 1. 새로 들어간 그림

| 파일 | 설명 | 크기 |
|---|---|---|
| `images/characters/벨_진지.webp` | 입꼬리만 살짝 내려간 기본 표정 | 1116×2000, 94KB |
| `images/characters/벨_지목.webp` | 누군가를 가리키는 표정 | 1116×2000, 95KB |
| `images/characters/벨_고뇌.webp` | 턱에 손을 대고 고뇌하는 표정 | 1116×2000, 91KB |
| `images/characters/벨_놀람.webp` | 대단히 경악하는 표정 | 1116×2000, 93KB |
| `images/characters/니콜_당황.webp` | 더 당황하는 표정 | 1116×2000, 137KB |

- 배경은 이전 그림들과 같은 방식(rembg `isnet-anime` + 가장자리 정리)으로 지웠어. 오른쪽 아래 워터마크도 같이 지워졌어.
- 위치는 따로 맞출 필요가 없었어. 기존 그림(벨_노말, 니콜_진지)과 겹쳐서 재 보니 하체는 1.1px 이내, 모자 챙은 1.2px 이내(1116px 기준, 폰 화면에서 0.4px 정도)로 이미 같은 자리였어. 그래서 이동이나 확대 없이 그대로 썼어.
- 게임에서 확인했을 때 벨의 위치와 크기는 표정이 바뀌어도 완전히 같아(모든 표정에서 x=-189, y=228, 544×976).
- 폰에서 늘어나는 정도는 1.46배야(벨 `h` 250.2 → 폰 화면 약 2927px ÷ 2000px). 기존 `벨_노말`(1340×2400)은 1.22배라서, 새 그림이 아주 조금 덜 선명할 수 있어. 기준(1.8배 이하)은 넘지 않아.

## 2. 코드에서 바꾼 것 (두 줄)

`bokbok27_3.twee`와 `index.html`의 `CHAR` 표:

```
'벨':   { imgs: ['진지', '노말', '지목', '고뇌', '놀람'], base: '진지', ... }   // 전: imgs ['노말'], base '노말'
'니콜': { imgs: ['진지', '당황'], base: '진지', ... }                           // 전: imgs ['진지']
```

- **벨의 기본 표정이 `노말`(웃는 얼굴)에서 `진지`로 돌아왔어.** 표정 표시가 없는 장면은 모두 진지 표정이야. 예전(`v0.07`)에도 기본이 진지였고, 화질 정리 때 임시로 노말이 기본이 됐었어.
- 이미 있던 `벨:노말` 표시 23곳(웃는 장면)은 그대로 노말이 나와.
- 미리 받기 목록(`assetList`)은 `CHAR`의 `imgs`를 읽어서 만들어지니까 새 그림은 자동으로 목록에 들어가. 미리 받기 코드는 안 건드렸어.

## 3. 장면 배치 (표시 41곳)

장면 글 맨 위에 `<span data-bx="벨:지목"></span>` 한 줄씩 넣었어(대사 글은 안 고침). 번호는 `제목 없는 구절 N`의 N이야.

| 표정 | 곳수 | 장면 | 고른 기준 |
|---|---|---|---|
| 지목 | 21 | 35, 65, 67, 69, 71, 112, 122, 125, 148, 176, 178, 180, 182, 184, 185, 236, 241, 245, 252, 255, 312 | 벨이 누군가를 범인으로 몰거나 지적하는 대사 |
| 놀람 | 9 | 시작3, 시작4, 시작5, 시작6, 118, 126, 207, 269, 301 | 귤복복 시체 발견, 포포에게 물림, "비장의 수?!", "그런 잔인한!!" 같은 경악 |
| 고뇌 | 10 | 34, 127, 144, 244, 265, 267, 278, 279, 280, 281 | "한참을 고뇌하던 벨", 생각에 잠긴 혼잣말, 결정을 앞둔 독백 |
| 니콜 당황 | 1 | 221 | "차 한 대 값이 없어졌다고!!" |

- 나머지 벨 장면은 기본 `진지`(132곳), 웃는 장면은 `노말`(23곳)이야.
- 니콜은 217, 219번에서 기본 표정으로 두었어(추궁과 비꼬는 말투). 터지는 221번만 당황이야.
- 예전 기록(`v0.04`)에 있던 `놀람` 표시 중 92~95, 102번은 **벨이 무대에 없는 장면**이라 넣지 않았어(수나 권총 장면 등). 넣어도 화면에 안 나와.

## 4. 확인한 방법

- **구조 검사**: 패시지 369개가 `twee`와 `html`에서 글자 단위로 같고, 깨진 링크 0, 엔딩 17개 (오류 0, 경고 0).
- **312개 장면 전수**: 실제 엔진으로 모든 장면을 열어 나오는 인물과 표정이 기대한 대로인지 확인 (불일치 0, 에러 0, 404 0). 검증기의 인물 표 파일이 옛날 것이라, 먼저 새 `CHAR` 표에서 다시 만들었어.
- **표정이 실제로 나오는지**: 표시한 41곳이 모두 화면에 나오는지 장면별로 확인. 처음 넣은 92~95, 102번이 안 나오는 것을 이 검사에서 찾아 지웠어.
- **눈으로 확인**: 시작4(놀람), 112(지목), 144(고뇌), 34(선택지 장면의 고뇌), 221(니콜 당황), 177(기본 진지)을 폰 크기(390×844)로 찍어 봤고, 지목 21곳은 한 장에 모아서 손이 상대 얼굴을 가리지 않는지 봤어.
- **무작위 플레이 20판**(390×844 12판, 360×640 8판): 처음부터 끝까지 선택지를 무작위로 골라 엔딩까지 가고, 에러와 멈춤 0.
- 엔딩 화면, 선택지 클릭, 대사창 탭, 시시아의 때리는 연출, 타이틀도 다시 확인했어(결과는 PR 본문 참고).

## 5. 앞으로 남은 것

- 새로 받은 그림은 **벨 진지**(표정 요청 목록의 1순위)뿐이라, 아스트라 진지(24장면)는 아직 그림이 필요해. (`docs/새_그림_요청_목록.md` 참고)
- 표정을 더 늘리려면 `CHAR`의 `imgs`에 이름을 적고 `images/characters/이름_표정.webp`를 넣은 뒤, 장면 글에 `<span data-bx="이름:표정"></span>`을 넣으면 돼.
- 장면 배치가 어색하면 알려줘. 해당 장면 번호의 표시 한 줄만 바꾸면 돼.
