# 자오 `기분나쁨` 표정 그림 적용 보고서

받은 그림(원본은 따봉하는 자오를 무표정에 가까운 "기분 나쁜" 표정으로 다시 그린 것)을 화질 검사하고, 게임에 넣고, 어느 장면에서 쓰는지 정했어.

## 1. 화질 검사 결과: 통과

| 항목 | 새 그림 | 비교 |
|---|---|---|
| 원본 크기 | 1536×2752 | 지금 게임 그림은 1116×2000(큰 그림), 1340×2400 |
| 선 선명도(2000px 높이로 맞춘 가장자리 폭, 작을수록 선명) | 1.45px (저장본 1.52px) | 지금 `자오_노말` 1.88px. 지금 게임 그림들(범위 1.37~1.91) 중 선명한 쪽 |
| 늘린 흔적(고주파 에너지 비율) | 0.103 | 게임 그림들 0.09~0.14 범위. 해상도를 늘렸을 때 생기는 뚝 끊기는 현상 없음 |
| 폰에서 늘어나는 정도 | **0.96배**(늘어나지 않음) | 지금 `자오_노말`은 1.15배 |

- 폰 계산: 자오 `h` 196.5 → 폰 화면(390px, 배율 3) 약 2299px. 새 그림 2400px에 맞춰 저장.
- 흰 배경 위의 **흰 털**(다리 털, 손과 발)이 누끼에서 날아갈 걱정이 있어서 확대해서 봤는데, 털과 윤곽선 모두 그대로 남았어.
- 그림 속 앞치마에 알아볼 수 없는 글자(`ДИНРХ`)가 있어. 게임 화면에서는 반투명 대사창 뒤라 거의 안 보여. 신경 쓰이면 말해줘.

## 2. 넣은 것

- `images/characters/자오_기분나쁨.webp`: 1340×2400 webp 205KB. 원본(1536×2752)을 1340×2400으로 줄여서 저장. 폰 화면 기준 늘어나지 않는 크기이고, 화면에 열 때 메모리도 1536×2752(약 17MB)보다 적게(약 13MB) 써.
- 위치 맞춤: 기존 `자오_노말`과 겹쳐 보니 머리 0.75px, 다리 0.73px 차이(1117×2000 기준)에 크기 비율 1.001배라서 그대로 같은 틀이야. 게임에서도 두 표정의 크기와 자리가 같아(428×766).
- `CHAR` 표의 `'자오'` 한 줄: `imgs: ['노말', '기분나쁨']` (기본 표정은 `노말` 그대로).

## 3. 장면 배치 (10곳)

장면 글 맨 위에 `<span data-bx="자오:기분나쁨"></span>` 한 줄씩 넣었어. 번호는 `제목 없는 구절 N`의 N이야.

| 장면 | 자오의 상황 |
|---|---|
| 137 | "나한테는 알리바이 안 물어봐?" |
| 138 | 벨이 "자오 씨는 사람이 아니니까..." |
| 139 | "나는 토끼 시렌이야. 엄연히 세금 내고 산다고." |
| 142 | "다이아린, 너 지금 날 '토끼'라고 부른거야?" |
| 252 | 벨이 "당신은 시렌이 아닙니다." |
| 254 | "그렇다는 건...?!" |
| 255 | 벨이 "이게 어딜 봐서 시렌이야." |
| 256 | "야" |
| 307 | "반악 씨까지..." |
| 311 | "?!" |

- 135, 136번은 상황이 시작되는 장면(벨이 "당신은 상관 없어요"라고 하고 자오가 "?"라고 되묻는 것)이라 기본 `노말`로 뒀어.
- 이야기 흐름대로 이어지는 장면 중 자오가 무대에 있는 곳은 이 12곳이야(검증기로 전부 찾음).
- 따봉하는 `노말`은 웃거나 신나는 장면에 쓰도록 남겨 뒀어. 이후 자오가 나오는 장면을 새로 쓰면 기본은 `노말`이고, 억까를 당하는 장면에 `자오:기분나쁨` 한 줄만 넣으면 돼.

## 4. 확인한 방법

- **구조 검사**: `twee`와 `html`의 패시지가 글자 단위로 같고 깨진 링크 없음, 엔딩 17개 (오류 0).
- **312개 장면 전수**: 실제 엔진으로 모든 장면을 열어 나오는 인물과 표정을 확인 (불일치 0, 에러 0, 404 0).
- **눈으로 확인**: 135, 139, 142, 255, 307, 311번을 폰 크기로 찍어서 확인.
- **무작위 플레이 20판**(390×844 12판, 360×640 8판): 처음부터 선택지를 무작위로 골라 엔딩까지 갔고, 에러와 멈춤 0 (서로 다른 엔딩 9가지와 6가지).
- **그 밖의 회귀 검사**: 엔딩 17개(이상 0), 선택지 클릭 48곳(이상 0), 대사창 탭, 시시아 연출, 타이틀 모두 정상.
- 구조 검사의 경고 1건(`아스트라_당황.webp`가 안 쓰임)은 다른 Claude가 `main`에 넣은 그림이라 내 변경과 무관해.
