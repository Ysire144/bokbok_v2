# 캐릭터 그림 정리 보고서 (v0.12)

표정별 그림은 나중에 다시 뽑기로 하고, **캐릭터마다 화질이 좋은 그림 한 장만 남기고 화질이 나쁜 그림은 버렸어.** 아래는 정확히 무엇을 했는지야.

## 1. 한 일 한눈에

| 항목 | 전 (v0.11) | 후 (v0.12) |
|---|---|---|
| 캐릭터 그림 파일 | 41장 | **29장** (캐릭터마다 1장) |
| 그림 총 용량 | 4.6MB | 4.0MB |
| 작은 그림(높이 1100px 미만)이 나오는 비율 | 65% (390번 / 603번) | **20%** (122번 / 603번) |
| 큰 그림이 나오는 비율 | 35% (213번 / 603번) | **80%** (481번 / 603번) |
| 그림을 전부 메모리에 올렸을 때 | 약 226MB | 약 213MB |

- "나오는 번호"는 312개 장면에서 화면에 나오는 그림 수(한 장면에 최대 2명)야.
- 전체 312장면을 실제 게임으로 열어서 **나오는 사람과 그림이 기대한 대로인지 확인했고 불일치 0, 에러 0, 못 찾은 그림 0**이야.

## 2. 규칙

1. 캐릭터에 **큰 그림(높이 1100px 이상)이 있으면 그 그림 한 장만** 남기고, 작은 그림(높이 720px 이하)은 지웠어.
2. 캐릭터에 **작은 그림밖에 없으면 그대로 둬.** 지우면 화면에 "이미지를 못 찾았어" 상자가 떠서, 새 그림이 올 때까지 임시로 쓰는 거야.
3. 표정 표시(`<span data-bx="벨:노말"></span>`)는 **하나도 안 지웠어.** 92개 모두 남은 그림과 맞고, 나중에 표정 그림이 생기면 그대로 다시 살아나.

## 4. 얼굴 위치를 어떻게 지켰나

기본 그림이 바뀌면 그림 안에서 눈의 위치가 달라져서, 그림이 바뀐 만큼 얼굴이 옆으로 밀릴 수 있어. 그래서 이렇게 했어.

- 지운 작은 그림과 남긴 큰 그림을 **이미지 정합(ECC)**으로 겹쳐서 눈의 위치와 크기 차이를 쟀어.
- 12명 중 10명은 두 그림이 **완전히 같은 구도(눈 위치 차이 0.3px 이하, 402×720 기준)**라서 배치 수치를 그대로 뒀어. 가로세로 비율(`ar`)만 새 그림에 맞췄어.
- 2명은 구도가 달라서 눈 위치와 크기를 새로 잡았어.
  - **수나:** 얼굴붉힘 그림이 기본 그림보다 눈이 세로로 약 1.7px(402×720 기준) 아래에 있고 배율이 0.25% 작아서 `ey` 0.1879→0.1902, `h` 185.2→185.7로 고쳤어.
  - **남궁우:** 노말 그림이 기본 그림과 자세가 조금 달라서 `ex` 0.6374→0.6549, `ey` 0.1979→0.1919, `h` 237.7→238.7로 고쳤어. 예전에 넣어 둔 보정값(`adj`)은 이 새 수치에 합쳐서 없앴어.
- 확인: 이전 버전과 새 버전을 같은 장면으로 찍어서 얼굴 위치를 겹쳐 비교했어. 폰 화면(가로 390px) 기준으로 12명 중 7명은 어긋남이 0.1px 미만이고, 나머지는 네코미야 0.3px, 아스트라 0.1px, 시시아 0.5px, 남궁우 0.7px, 수나 1.5px(수나는 위에서 고친 만큼)야. 비교 그림은 `docs/화질정리_얼굴비교.jpg`야. (왼쪽이 이전, 오른쪽이 이번. 표정이 다른 건 기본 표정이 바뀐 거야.)

## 5. 달라진 점 (플레이하면 보이는 것)

- **기본 표정이 바뀌었어.** 전에는 대부분 "진지"(입꼬리 살짝 내려감)가 기본이었는데, 이제 남은 그림의 표정이 기본이야. 그래서 이 캐릭터들은 **항상 이 표정**으로 나와.
  - 벨, 아스트라, 빛나, 시드, 네코미야, 앨리스, 록시, 벨리나, 시시아, 남궁우: **살짝 미소(노말)**
  - 다이아린, 루시아, 의현: **무표정**
  - **수나: 얼굴을 붉힌 표정(얼굴붉힘)**. 이건 원래 특정 장면용 표정이라, 모든 장면에서 수나가 얼굴이 빨개져 있어. 어색하면 작은 진지 그림을 잠깐 되살리는 게 나을 수도 있어 (아래 "확인이 필요한 것" 참고).
- **벨이 제일 많이 바뀌었어.** 벨은 171장면에서 진지 표정이었는데 이제 모든 장면에서 미소야. 진지한 추궁 장면에서도 웃고 있게 돼.
- **선명도는 크게 좋아졌어.** 그림이 나오는 횟수의 80%가 큰 그림이라 폰에서 0.9~2.3배로만 늘어나(전에는 대부분 4배 이상). 표정이 바뀔 때 선명도가 튀던 문제도 없어졌어.

## 6. 안 바뀐 것

- 장면 글, 표정 표시(`data-bx`), 출연자 지정(`data-stage`), 자리 규칙, 앞뒤 순서 표(`PAIR`), 선택지 화면, 대사창 클릭 등은 그대로야.
- 엔딩 그림, 타이틀 그림, 배경은 이번에 건드리지 않았어.

## 7. 확인이 필요한 것

1. **수나의 기본 그림**: 얼굴붉힘 한 장만 남아서 모든 장면에서 붉어져 있어. 원칙대로 했지만 이상하면 말해줘.
2. **벨 진지 그림이 필요해.** 제일 많이 나오는 캐릭터라서, 표정 그림을 다시 뽑을 때 벨과 아스트라의 진지가 제일 먼저 필요해.
3. **작은 그림 12명**은 새 그림이 오기 전까지 4배 가까이 늘어난 채로 나와. 야나기(768×1376)도 나머지보다 조금 덜 선명해.
4. **표정 그림이 다시 생기면** 그 캐릭터의 `imgs`에 표정 이름을 넣고 `base`를 원래 기본 표정으로 되돌리면 돼. 표정 표시 92개가 그대로 살아나.
5. **캐시**: 남긴 큰 그림은 파일 이름과 내용이 그대로라 영향이 없어. 다만 v0.11에서 교체한 클라렛, 야나기, 레미엘은 파일 이름이 같아서, 이미 해 본 사람의 브라우저에는 예전 그림이 잠깐 남을 수 있어.
