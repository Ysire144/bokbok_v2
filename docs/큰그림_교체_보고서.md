# 큰 그림 교체 보고서 (v0.16)

작은 그림(402×720 안팎)이 남아 있던 **11명을 전부 큰 그림으로 교체했어.** 이제 29명 전부가 큰 그림이야.

## 1. 결과

| 항목 | 전 (v0.15) | 후 (v0.16) |
|---|---|---|
| 큰 그림(세로 1100px 이상)을 가진 캐릭터 | 18명 | **29명 (전부)** |
| 작은 그림이 나오는 비율 | 18% (110번 / 603번) | **0%** |
| 폰(화면 배율 3)에서 늘어나는 배율 | 작은 그림 3~4.6배 | **전부 0.9~2.3배** (야나기 2.34, 반악 2.28, 나머지 1.7배 이하) |
| 그림 총 용량 | 약 4.1MB | 약 5.0MB |
| 그림을 전부 메모리에 올렸을 때 | 약 213MB | 약 308MB |

## 3. 어떻게 처리했나

- 새 그림 중 반악, 미야비, 이블린, 트리거, 아리아는 흰 배경이었어. 애니 그림용 배경 제거로 지우고 가장자리를 다듬었어. 나머지(귤복복, 11호, 유즈하, 버니스, 니콜, 포포)는 투명 배경이 이미 들어 있었어.
- 우하단의 ✦ 워터마크는 배경과 함께 없어졌어.
- 파일은 `이름_진지.webp`로 덮어썼어(webp 품질 84).
- **구도를 기존 그림과 정합해서 눈 위치와 크기를 쟀어.** 10명은 완전히 같은 구도(차이 0.05px 이하)라서 배치 수치는 그대로 두고 가로세로 비율(`ar`)만 새 그림에 맞췄어. **귤복복만** 크기가 2.5% 달라서 `h` 206.2→211.5, `ex` 0.4114→0.4036, `ey` 0.1949→0.1945로 고쳤어.
- 지난번에 받은 귤복복(629×842)은 해상도가 부족해서 불합격이었고, 이번 1117×2000 그림으로 대체했어. 11호는 두 번 받은 것 중 두 번째(재시도)를 썼어.

## 4. 검증

- **312개 장면 전부**를 실제 엔진으로 열어 출연자와 그림이 기대한 대로인지 확인했어 (불일치 0, 에러 0, 404 0).
- 교체 전과 후를 같은 장면으로 찍어서 얼굴 위치를 겹쳐 비교했어. 11명 모두 폰 화면 기준 **0.5px 이내**야(반악, 트리거, 유즈하, 버니스, 니콜, 포포는 0.1px 미만).

## 5. 확인이 필요한 것

1. **메모리**: 29명 전부 큰 그림이 되어 그림을 전부 메모리에 올렸을 때 약 308MB야(이전 약 213MB). 게임은 필요한 그림만 받아서 쓰지만 뒤에서 나머지를 미리 받아두기 때문에, 오래된 폰에서는 부담이 될 수 있어. 대책은 두 가지야.
   - **그림 아래쪽 30%를 잘라서 쓰기** (화면에 안 보이는 부분이라 메모리와 용량이 약 30% 줄어. 얼굴 위치는 내가 다시 맞춰).
   - 포포(2000×2000, 한 장에 약 16MB)만 1600×1600으로 줄이기.
   느린 폰과 느린 회선 테스트(체크리스트 4번)에서 실제 수치를 보고 정하면 돼.
2. 야나기와 반악(2.3배)은 원본이 768×1376이라 나머지보다 덜 선명해.
3. 이미 게임을 해 본 사람은 파일 이름이 같아서 브라우저 캐시 때문에 한동안 예전 그림이 보일 수 있어.
4. 표정 그림은 아직 한 번에 처리하기로 한 상태야 (`docs/새_그림_요청_목록.md` 참고).
