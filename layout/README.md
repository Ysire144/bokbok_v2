# layout: 캐릭터 배치 예시를 올리는 폴더

직접 만든 배치 예시(PPT 슬라이드 그림)를 이 폴더에 올려주세요.

- 체크리스트: `배치_경우의수.md` (번호 1~29)
- 파일 이름은 체크리스트 번호와 조합을 앞에 붙여주세요. 예: `02_벨+레미엘.png`, `01_벨혼자.png`
- PPT 파일(`.pptx`)도 같이 올려도 돼요.
- 슬라이드를 PNG로 내보낸 그림도 같이 올려주면 게임 화면과 겹쳐서 비교할 수 있어요.
- 슬라이드 크기는 세로 9:16 (예: 너비 9, 높이 16)이면 게임 화면과 똑같이 옮길 수 있어요.
- 게임에서는 화면 아래쪽 28%를 대사창이 가리고, 벨은 항상 왼쪽, 상대는 항상 오른쪽이에요.
